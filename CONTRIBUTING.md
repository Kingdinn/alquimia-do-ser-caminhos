# Como contribuir

Use Node.js 24, instale com `npm ci` e configure `.env.local` a partir do exemplo. Desenvolva com dados fictícios e um Supabase separado da produção.

Antes de propor uma mudança, explique o problema e o comportamento esperado. Mantenha português, espanhol e inglês consistentes, preserve navegação por teclado e respeite movimento reduzido. Alterações de salvamento devem preservar conflitos, rascunhos e isolamento por conta.

Execute `npm test`, `npm run typecheck` e `npm run build`. Para mudanças na interface, confira desktop e celular. Mudanças em autenticação, banco ou imagens precisam de testes entre duas contas independentes.

No pedido de revisão, descreva o que mudou, como foi verificado e qualquer limitação. Não inclua dados pessoais, dumps, credenciais nem capturas de cadernos reais.

A licença principal ainda está pendente de escolha do mantenedor. Contribuições externas devem começar após sua definição; preserve os avisos e licenças de terceiros.
